# HTTP Fundamentals — Study Guide

A comprehensive, visually structured study guide covering HTTP from first principles through advanced topics — built for network/security engineers studying for interviews, certifications, or just leveling up on protocol internals.

## 📖 What's Inside

The guide is organized into 15 sections, progressing from basics to advanced:

| # | Section | Topics |
|---|---------|--------|
| 1 | What is HTTP | Client-server model, request-response flow, end-to-end web flow |
| 2 | HTTP as an Application-Layer Protocol | OSI/TCP-IP mapping, encapsulation |
| 3 | URL/URI Structure | Scheme, host, port, path, query, fragment |
| 4 | Stateless Nature of HTTP | Why HTTP has no memory, how statelessness is worked around |
| 5 | HTTP vs HTTPS | Encryption, integrity, authentication |
| 6 | Request & Response Basics | Request/status lines, headers, message body |
| 7 | HTTP Methods & Status Codes | GET/POST/PUT/PATCH/DELETE, 1xx–5xx families, safe vs idempotent |
| 8 | Headers Deep Dive | Request/response headers, content negotiation, CORS |
| 9 | Sessions, Cookies & State | Cookie attributes, session management, Web Storage API |
| 10 | Caching & Performance | Cache-Control, ETag, CDNs, compression, keep-alive |
| 11 | HTTPS / TLS | TLS handshake, certificates, SNI, HSTS, mixed content |
| 12 | HTTP/2 & HTTP/3 Internals | Multiplexing, HPACK, server push, QUIC |
| 13 | Proxies, Gateways & Inspection | Forward/reverse/transparent proxies, SSL inspection, WAF, load balancing |
| 14 | Troubleshooting & Tooling | Wireshark, curl, DevTools, log correlation, synthetic monitoring, WebSockets |
| 15 | HTTP/1.1 vs HTTP/2 vs HTTP/3 | Full comparison table |
